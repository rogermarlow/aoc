My solutions to some of the Advent of Code challenges since 2022.

Generally in Ruby, the solution is either `answer.rb` or
`part[12].rb`. The challenge input is always `input.txt` but this is
not in the repo as requested by AOC. Retrieve inputs from
[https://adventofcode.com](https://adventofcode.com).

Smaller test files are in the repo and typically called `test.txt` or
`tiny.txt` and are typically the given examples from the AOC site.

Solutions usually take the input file name as the argument: `./part1.rb input.txt`
